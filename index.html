Charge le corps humain MakeHuman

L'appli construit ton perso à partir des données libres de MakeHuman. Elles se chargent une seule fois, puis restent sur l'appareil.

  1. Sur ton PC, télécharge l'extension MPFB sur extensions.blender.org (bouton « Download », un .zip d'environ 43 Mo) : elle contient le corps de base et toutes les formes.
  2. Télécharge aussi le pack « MakeHuman system assets » sur la page Asset packs de makehumancommunity.org : yeux, cils, sourcils, cheveux, dents.
  3. Donne les deux .zip à l'appli, sans les décompresser.

Tu peux aussi glisser les fichiers sur cette zone.
